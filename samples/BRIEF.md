# 見た目サンプル30案 — 制作ブリーフ

## 0. これは何か(目的)
「**ビジュアルシンカーのための、新しいエディタ**」の見た目の参考例を、HTML 30個で作る。
- AIがコードを書いてくれる時代、エディタは「コードを書きやすい」よりも **「使い始めたい」と思えるか** が大事。
- 見た目を自分の好きな形に作れる。手書きで自由に囲んだり、線で結んだりできる **ボード**。
- ディレクトリを **プロジェクトとして記憶** し、ボード上のカードをクリックすると **従来のエディタ(VSCode風)** が現れ、コーディングもできる。
- エディタは、マークダウンを書く / コードを読む・書く / **コードレビュー**(差分とコメント)/ AIとの会話 ができる。

## 1. 参考画像(必ず見ること): `samples/reference/`
- `ref1-pamphlet.webp` … 旅のしおり。方眼紙、深緑の枠、縦のタイムライン(丸い時刻ラベルが線でつながる)、黒い「DAY 1」ピル、吹き出し、ポラロイド風の写真、折りたたみ構造。
- `ref2-editorial.webp` … 台湾の旅の本。白い紙面に太い黄色の縦帯、大きな明朝の「W1 W2 S1」索引記号、細い線と黒丸で項目を結ぶ、黄枠/三角のアイコンバッジ、ぷにぷにしたマスコット、円形の写真、右端の縦タイムライン。
- `ref3-travelers-notebook.webp` … トラベラーズノート。クラフト紙、紺のマスキングテープのラベル、赤いステッカーのカード、丸いドットシール、手書きの地図と落書き、数字ステッカー、スタンプ。
- 共通するのは「素材感のある紙もの」×「地図・タイムライン・コネクタ線で情報をつなぐ編集デザイン」×「手書きの温かさ」。**著作物の複製は不可**。雰囲気と発想だけを借りて、独自の絵と配色で作ること。

## 2. 技術契約(必読): `samples/assets/common.js` の先頭コメント
見た目(HTML/CSS/インラインSVG)だけを作る。ふるまいは `common.js` が持つ(**編集禁止**)。
各サンプルは `samples/NN-slug.html` の **単一ファイル**(+ `assets/common.js`)。

必須要素:
1. `<body data-view="board">`、`<div id="board">`、`<div id="editor">` を同じ階層に。
2. `<meta name="ml-title" content="…">` と `<meta name="ml-concept" content="…(コンセプトを1〜2文)">`(「この見本について」の目的・目次が自動で出る)。
3. ボード: プロジェクトカード **5枚**(`data-project` と `data-drag`、`position:absolute; left/top`)。ID と表示名は下記。
   `<svg id="deco">`(丸囲み・コネクタ用)と `<svg id="pen">`(手書きペン用、最前面)、ペンのON/OFFボタン `data-action="pen"`、色ボタン `data-pen-color`(3色以上)、`pen-undo`、`pen-clear`。
4. ボードに **`MemoLab.link` のコネクタ線を2本以上**、**`MemoLab.around` の手書き丸囲み/下線/ハイライトを2つ以上**、`MemoLab.scribble` の落書きを1つ以上(`MemoLab.ready(function(){…})` の中で)。
5. エディタ: `data-slot` の **tree / tabs / doc / chat / title / path / branch** を全部置く(`lang` `blurb` `count-review` は任意)。戻るボタン `data-action="back"`。
6. ボード→エディタの **切り替えアニメーションをCSSで作る**(`body[data-view]`, `body[data-phase]`, `--ox --oy`)。コンセプトに合った独自の演出にする(ページをめくる、ズームイン、ファイルを引き出す、ドアが開く、等)。**非アクティブ側は opacity/transform で消し、`display:none` にしない**。
7. スクリーンショット確認用ハッシュ: `…html#open=todo-app&file=review/完了トグルの追加.diff` でエディタ表示になる。

プロジェクトID(カード5枚):
| data-project | 表示名 | 中身 | 言語タグ |
|---|---|---|---|
| `todo-app` | ToDoアプリ | React+TS の小さなタスク管理 | TypeScript |
| `sales-analysis` | 売上データ分析 | 月別推移と前年比 | Python |
| `dbt-snowflake` | dbt × Snowflake | staging→marts のモデル整理 | SQL / dbt |
| `life-plan` | 人生設計 2027-2029 | 3年後の自分を言葉にする(コードなし、マークダウンのみ) | Markdown |
| `memo-editor` | このアプリ自身 | いま作っているメモ型AIエディタ | Rust + TypeScript |

ファイル名の例(エディタの見た目確認に使う):
- マークダウン: `#open=life-plan&file=3year-plan.md&mode=split`
- コード: `#open=sales-analysis&file=analyze.py` / `#open=dbt-snowflake&file=models/staging/stg_orders.sql`
- レビュー(差分+コメント): `#open=todo-app&file=review/完了トグルの追加.diff`

## 3. 品質ルール(前回「ダサい」と言われた反省)
前回の失敗: 光源がバラバラ、素材感がない、小物が記号的、平坦で奥行きがない、フォントがありきたり。
- **色は4〜6色に絞り、`:root` のCSS変数で定義**。配色の理由をCSSコメントに1行。
- **素材感**: 紙・布・金属などは、SVG `feTurbulence` のノイズ、複数重ねのグラデーション、2層以上の影(近い影+遠い影)、縁の凹凸、折り目、半透明、`mix-blend-mode` などで本物らしく。光源(影の向き)は全体で統一。
- **小物は自作のインラインSVG**(クリップ、テープ、ピン、ステッカー、スタンプ、マスコット等)。絵文字は使わない。少し歪ませ、線の太さに強弱をつける。ベタ塗りの記号っぽさを避ける。
- **構図**: 非対称で、重なり・大小・余白にリズムを。カードの大きさ/回転/高さに差をつける。情報(タイトル・言語・ブランチ・レビュー件数・最終更新)を、コンセプトに合う形(索引記号、ラベル、スタンプ、タイムライン等)で見せる。**5枚が同じ形の並びは不可**。
- **タイポグラフィ**: Google Fonts を使ってよい(`<link>`)。日本語対応の個性あるフォント(例: Yomogi, Klee One, Zen Kurenaido, Zen Maru Gothic, Shippori Mincho, Dela Gothic One, DotGothic16, Kiwi Maru, Reggae One, Hachi Maru Pop, Potta One, Kaisei Decol, Zen Antique, RocknRoll One 等)。**オフラインでも崩れないフォールバック**を必ず書く。
- **エディタは「使えそう」に見せる**: コード部分は等幅フォントで読みやすく(コントラスト確保、行番号・タブ・ツリー・差分の色分け・コメント吹き出し・チャット)。**装飾は枠・タブ・ツリー・コメントなど周辺に寄せ、コード本文の背景は読みやすく**。ボードは遊び心を強く、エディタは抑えめに。
- 1440×900 で崩れないこと(横スクロールなし、文字のはみ出しなし)。コンソールエラーなし。
- 画像ファイル禁止(インラインSVG/CSSのみ)。外部は Google Fonts だけ。
- 内容は日本語。ダミーの会話は `common.js` が出す。

## 4. 検証手順(必ず自分で行い、見て直す)
Edge のヘッドレスでスクリーンショットを撮り、画像を Read して確認する(PowerShell):
```powershell
$edge="C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"
$base="file:///C:/Users/ashun/Documents/00_active/memo_editor/samples"
$out="C:\Users\ashun\Documents\00_active\memo_editor\samples\thumbs\NN-board.png"
Start-Process -FilePath $edge -Wait -NoNewWindow -ArgumentList @("--headless=new","--disable-gpu","--hide-scrollbars","--user-data-dir=$env:TEMP\mlprof_NN","--window-size=1440,900","--virtual-time-budget=4000","--screenshot=$out","$base/NN-slug.html")
```
- ユーザーデータ dir は **自分専用の名前**(他のエージェントと衝突しない)。1回ずつ `-Wait` で実行する。
- 撮るもの: ボード / マークダウン(`mode=split`)/ コード or レビュー の **最低3枚**(`thumbs/NN-board.png`, `NN-md.png`, `NN-review.png`)。
- 見るポイント: ダサくないか、はみ出し、重なり、読みにくさ、素材感、配色。**直して撮り直す**を最低1回は行う。
- 切り替え演出は静止画では見えないので、CSSを読み直して矛盾がないか確認する。
